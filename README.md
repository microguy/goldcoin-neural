## Tech Stack

### Core (Rust + Python)
- **Rust**: Memory-safe core, blockchain interaction
- **Python**: AI/ML models, rapid prototyping
- **ONNX Runtime**: Cross-platform neural network execution

### AI Layer
- **Language Model**: Custom fine-tuned LLM for crypto operations
- **PyTorch**: Training and inference
- **Reinforcement Learning**: Transaction optimization

### Interface
- **WebAssembly**: Universal runtime (browser, desktop, mobile)
- **React**: Declarative UI that the AI can modify
- **Voice**: Natural speech interface

### Data
- **DuckDB**: Embedded analytics
- **IPFS**: Distributed model storage
- **Vector DB**: Semantic transaction search
